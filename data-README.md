# Dataset
Place `COVID-19 Coronavirus.csv` in this folder.

It has 225 rows and these columns: Country, Other names, ISO 3166-1 alpha-3 CODE, Population, Continent, Total Cases, Total Deaths, Tot Cases//1M pop, Tot Deaths/1M pop, Death percentage.

**Source:** add the link to where you downloaded it, and check that its license allows redistribution before committing the CSV.
